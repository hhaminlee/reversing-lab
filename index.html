앱 리버싱 실습 교재

OWASP의 연습용 앱 UnCrackable을 풀면서 바이트, 암호화, 어셈블리를 기초부터 익히는 한국어 교재입니다. 어셈블리가 처음이라면 0부부터 시작하세요.

0부

내 코드 뜯어보기

직접 쓴 C 코드를 컴파일해서 어셈블리와 한 줄씩 짝지어 봅니다. 변수, 함수, if, 반복문, 문자열, 포인터.

 1부

리버싱 첫걸음

바이트, 16진수, Base64, AES와 패딩, 비트 플래그를 익히고 UnCrackable Level 1을 풉니다.

 2부

리버싱 둘째 걸음

네이티브 코드, 레지스터, 리틀 엔디안을 익히고 objdump로 UnCrackable Level 2를 풉니다.
